# Widgets and shortcuts (Pro)

Pro-only home-screen widgets and launcher shortcuts.

## Home-screen widgets

| Widget | Behavior |
|--------|----------|
| Server toggle | Start/stop the server from the home screen |
| Server info | Shows status / address / activity; can toggle start/stop |

Shared busy-state handling prevents double-taps while starting/stopping and refreshes widgets.

Free builds omit widget providers from the Free manifest.

## App shortcut

Launcher long-press shortcut can start the server via Splash after permissions.

## Notifications (both flavors)

Ongoing FGS notification (not Pro-exclusive):

- Shows the advertised server URL
- Stop action

See [../operations/notifications.md](../operations/notifications.md) and [../operations/foreground-service.md](../operations/foreground-service.md).
