# Web client (`client_HttpFS/`)

Not a Gradle module. Vue 3 + TypeScript source for the browser file manager at `/files/` and the browser info dashboard at `/info/`.

## Pipeline

```text
client_HttpFS/src/  --npm run deploy-->  app/src/main/assets/web/template/
                                              │
                                              ▼
                                  Browser: /web/template/...
                                  HtmlBuilder injects config.js at runtime
```

## Commands

```bash
cd client_HttpFS
cp .env.example .env
npm install
npm run dev      # Vite dev server; proxies API to HTTPFS_ORIGIN
npm run build    # → client_HttpFS/dist/
npm run deploy   # build + replace assets/web/template/
```

Requires **Node 20.19+**. After deploy, rebuild the Android APK.

## Stack

- Vue 3, Pinia, Vite 7
- CodeMirror 6 (text editor)
- i18n JSON under `client_HttpFS/src/assets/lang/`

## Runtime config

`config.js` is **generated by the server** (`HtmlBuilder`), not shipped as the live source of feature flags. It carries rights, feature flags, branding, language, user name, admin flag, etc.

## Editing tips

- Edit only under `client_HttpFS/src/`.
- `client_HttpFS/dist/` is build output.
- Keep public URL paths stable (`/web/template/...`, `/files/...`) unless server routes change too.
