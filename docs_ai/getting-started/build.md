# Build instructions

## Requirements

- JDK **17+** (Android Studio JBR is fine)
- Android SDK with **compileSdk 36** / build-tools as in `app/build.gradle`
- Android Studio or command-line Gradle wrapper (`./gradlew`)
- For web UI changes: Node.js + npm (see [../development/web-client.md](../development/web-client.md))

## Project modules

```text
settings.gradle → :app :free :pro :acme
```

- Flavors on `:app`: `free`, `pro`
- Build types: `debug`, `release`

## Common tasks

```bash
# Debug APKs
./gradlew assembleFreeDebug
./gradlew assembleProDebug

# Release APKs (needs signing — see below)
./gradlew assembleFreeRelease
./gradlew assembleProRelease

# Install on a connected device
./gradlew installProDebug
./gradlew installFreeDebug
```

Output APKs are named like `HttpFS-1.2.7.apk` (`archivesName` in `app/build.gradle`).

## Versioning

In `app/build.gradle`:

```text
versionMajor * 100000 + versionMinor * 1000 + versionPatch
→ versionName "major.minor.patch"
```

Update those three integers when releasing.

## Signing (release)

Optional local file: `gradle.properties.local` (gitignored). Property names are defined in the Gradle signing block — keep paths and passwords only on the machine that signs; never publish real values in documentation.

If missing, release builds still compile but may be unsigned depending on AGP/signing config presence.

## Flavor wiring

```groovy
free { applicationId 'tiar.ua.slf';  buildConfigField IS_PRO false }
pro  { applicationId 'tiar.ua.slf.pro'; buildConfigField IS_PRO true }
```

Dependencies: `freeImplementation project(':free')`, `proImplementation project(':pro')`, both use `:acme` as needed for SSL.

## Web client before shipping UI changes

```bash
cd client
npm install
npm run deploy   # builds and copies into app/src/main/assets/web/template/
```

Then rebuild the APK. Runtime `config.js` is still generated by the server (`HtmlBuilder`).
