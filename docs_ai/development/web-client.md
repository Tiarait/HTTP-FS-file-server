# Web client development

Source: **`client_HttpFS/`** (Vue 3 + Vite). User-facing UI map: [../user/web-client.md](../user/web-client.md).

## Setup

```bash
cd client_HttpFS
cp .env.example .env
npm install
```

## Develop

1. Run HttpFS on the phone or emulator (default HTTP port 8080 Free / 8081 Pro).
2. Set `HTTPFS_ORIGIN` in `.env` (default `http://127.0.0.1:8080`).
3. `npm run dev` — open `http://127.0.0.1:5173/files/` or `/info/`.
4. Edit files under `client_HttpFS/src/`.
5. `npm run build` — inspect `client_HttpFS/dist/`.
6. `npm run deploy` — replaces `app/src/main/assets/web/template/`.
7. Rebuild/install the Android app for on-device testing; hard-refresh the browser (cache).

**Folder sync** in dev works because Vite is on `localhost` (secure context). LAN `http://192.168.x.x` without HTTPS will not get `showDirectoryPicker`.

## Runtime `config.js`

Generated by `HtmlBuilder` when serving pages. Do not treat a hand-edited static `config.js` in assets as the source of feature flags.

## i18n

Language packs under `client_HttpFS/src/assets/lang/`. Server/app language settings influence which UI language is injected.

## Prefs sync

Logged-in users: `client_HttpFS/src/prefs/sync.ts` ↔ `GET/PUT /api/files/prefs`. Allowlist in `prefs/allowlist.ts`.

## Do not break URLs

Public paths such as `/web/template/...` and `/files/...` are coupled to Android route constants. Coordinate server + client changes.

See [../modules/client.md](../modules/client.md).
